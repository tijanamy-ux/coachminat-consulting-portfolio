# Coachminat Consulting Portfolio

A static, privacy-safe portfolio site for Coachminat Consulting.

## What it contains

- Coachminat positioning and methodology
- Public-safe selected work summaries for Lumident, Ceejayhome, CC Collection, Mr Olaleye and Amis Sales
- Service routes and trusted contact links
- No client contact data, private audit material, payment details, raw chats or unverified result claims

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy

This is a static Vercel site. Deploy the repository root with `vercel.json` included.
